# Attribution

These files are based on the [Arcanum Prompt Injection Taxonomy](https://github.com/Arcanum-Sec/arc_pi_taxonomy/)
created by Jason Haddix of [Arcanum Information Security](https://arcanum-sec.com/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Each file names the taxonomy code it comes from
(`PIT-T-…` for techniques, `PIT-E-…` for evasions).

**Changes made:** each technique/evasion is rewritten as a short Markdown brief (description, ideas,
examples) for a payload generator, aimed at indirect prompt injection through an uploaded meeting
transcript. Examples and ideas were added or adapted for this app. The taxonomy authors do not
endorse this project.
