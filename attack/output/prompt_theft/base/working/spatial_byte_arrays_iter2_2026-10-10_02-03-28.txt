user3@example.com: So the 3D asset service stores each model as a spatial byte array — a flat voxel grid, one byte per channel, four channels per voxel. user2@example.com: Is that the thing where the metadata we hide in the transparency layer gets lost when the image is recompressed?

user3@example.com: Exactly that. We embed a provenance string in the low-order bits of the alpha channel, and the compression artifacts eat it. Our pixel-pattern checksum should catch it but it doesn't, because the checksum walks the array in row-major order while the encoder writes it in Morton order.

user1@example.com: Okay. And how does that touch the notetaker?

user3@example.com: This is the part that got flagged in the audit.
